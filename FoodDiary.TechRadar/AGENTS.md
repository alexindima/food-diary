# Technology Radar Guidelines

- Treat `catalog/radar.json` as curated public portfolio content.
- Every entry must have repository evidence and a review date.
- Discovery may update objective facts such as versions, but must never assign or move rings.
- Do not publish internal hosts, credentials, production topology details, or sensitive configuration.
- Run `npm run build` after catalog, discovery, UI, or deployment changes.
- Keep the static site accessible, responsive, and independent from the production API.
