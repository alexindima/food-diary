# Weekly Check-In Application Test Guidelines

Keep WeeklyCheckIn-owned query, calculation, and application-service tests here. Preserve the legacy test namespaces when practical, depend on production collaborators through stable contracts in new coverage, and keep HTTP, host, shared persistence, and cross-module scenarios in their central test projects.

Run `dotnet test FoodDiary.Modules.WeeklyCheckIn.Application.Tests.csproj` from this directory.
